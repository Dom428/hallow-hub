# Hallow Hub

All your games in one place - part of the Hallow family with [Hallow Mixer](https://github.com/Dom428/hallow-mixer) and [Hallow Toolkit](https://github.com/Dom428/hallow-toolkit).

- **Finds your games by itself:** Steam, Battle.net and Epic Games, with real artwork from Steam's own on-disk cache (nothing is downloaded). Add anything else by its .exe.
- **Play from one place:** double-click a cover, or select it and press Play.
- **Playtime:** counted for any game running from its install folder, however you start it - today, this week, total, last played.
- **When a game starts:** switch Hallow Mixer to a preset you pick for that game, and/or turn on a Hallow Toolkit game session (Boost apps closed, High performance power). Everything goes back when the game closes.
- **Your Steam hours** show straight away; **update and size badges**; the same game in two stores is **one card** with a Play on choice.
- **Continue playing** row, a colour glow from each game's cover, and a **Stats** page (today, this week, 14-day chart, top games).
- **Game settings:** launch options, run as admin, and **collections** (your own groups, shown as filters).
- **Surprise me** picks something to play; **keyboard shortcuts** and **Xbox controller** support (only while Hub is in front).
- **Storage** page with clean-up suggestions; **session helpers** (apps that open with a game, break reminder, daily limit); **weekly recap**, streaks and CSV export; a **PC check** before you play.
- **Big Picture** full-screen mode for the couch (filters and collections on LB / RB, and Storage with the controller), and a **quick launcher** from the tray icon. Updates itself from GitHub.
- **Hallow family on every game page:** Saves (Hallow Vault: last backup, Back up now, Restore), Clips (Hallow Clips: this game's newest clips) and Overlay (Hallow Overlay on/off per game) - each only when that app is installed. Break reminders show on Hallow Overlay when it's running.
- **One Hallow icon:** Hub's tray icon hosts the whole family - each Hallow app (Mixer, Vault, Overlay, Clips, Remote, Keys and, from 2.13, Guard and Assist) gets a submenu with its own icon (its own actions, Open, Exit) and the others hide their own icons (Settings > One Hallow icon, on by default). From 2.13 any newer Hallow app that answers `menu` on its pipe gets a submenu too, without a Hub update.
- **Hallow Guard and Hallow Assist (2.13):** Guard's safety score is a small pill under *Your PC right now* (click it to open Guard), and Settings shows Guard's score, last scan and threats and whether Assist is in a session - all read from their status.json.
- **Power plan while you play (2.14):** Game settings > *Power plan while it runs* - pick a plan for this game or for all games (High performance, Ultimate Performance, Balanced or any plan on your PC). Hub switches to it when the game starts and back to the plan you had when it closes (not if you picked another one meanwhile). It only runs `powercfg /list`, `/getactivescheme` and `/setactive` as you - no admin, and plans are never created, changed or deleted. With the Hallow Toolkit game session on, the session picks the plan instead.
- **More of the family on the main page (2.14):** small cards next to Saves / Clips / Overlay - **Hallow Guard** (the family safety score, this week's change from the weekly report, and Windows hardening; click for the report), **Hallow Shield** (ads and trackers blocked today and this week, per browser in the tooltip; "Shield isn't sharing counts" with how to turn it on), and **Hallow Assist** (your own PCs with an online dot, and **Connect**, which opens Assist with that PC picked). Each card only shows when that app is there and new enough to share it.
- **Light and dark mode (2.15):** Hub follows the Hallow family's *Light / Dark / Same as Windows* choice in Hallow Toolkit (theme.json `mode`), live with no restart - *Same as Windows* follows Windows' app mode as it changes. Settings > **Look** picks Hub's own (*Follow Hallow*, *Light*, *Dark*). The light look keeps the Hallow accent (darkened where it's text, so it stays readable), drops the glows for clean borders, and switches the window's title bar too; game art keeps its own colours.
- **Light mode readability (2.16):** every small text in light mode reads at 4.5:1 or better - green, amber and lilac text use darker shades (icons and dots keep theirs), the accent as text is darkened against the darkest light panel, and a filled accent that would be hard to read (like violet with white text) gets a deeper shade, the same rule as Hallow Toolkit 5.16. Windows that are already open (game settings, emulators, What's new) switch light / dark and accent live too.
- **The whole family (2.17):** the **Family** button (next to Stats) opens a page with every Hallow app, grouped as *Play*, *Protect* and *Everyday* - each card says installed / running / not installed, its version, and a **live line from that app's status.json**: Hallow VPN *Connected - United States #5838 (IKEv2)* and its kill switch, Hallow Torrents *3 downloading · 12 MB/s* or *Locked - VPN off*, Hallow Browser's tabs and Shield, Hallow Email's unread count, Hallow Tasks' CPU / RAM / GPU, Hallow Financials *Vault locked / unlocked*, Hallow Home's Home Assistant connection, devices and cameras, Hallow Shield's browsers and blocked today, and Hallow Places' server (from an address you type; only its `/healthz` is read). **Counts and states only**: each app's file goes through a filter that keeps a short list of fields, so no subject, sender, torrent name, place, amount or address can reach a card. **Quick actions** over each app's pipe, only when you click: Connect fastest / Disconnect (VPN - never a NordLynx connect or disconnect, which would make Windows ask), Pause all / Resume all (Torrents), Lock now (Financials), Open and Settings. Results go to the status line - nothing pops up, during a game or otherwise. A missing app shows **Install**, which opens Hallow Setup (or the app's GitHub releases page) - Hub never downloads or runs an installer. In the Hallow icon the newer apps come after the others in a fixed order, and the ones you have that aren't running are under **Start a Hallow app**.
- **Switch Steam accounts (2.18):** the **Steam** button (next to Wishlist) and the Hallow icon list every account Steam remembers on this PC. Pick one: Hub closes Steam, sets that account to sign in (the same setting Steam's own *Change account* uses) and opens Steam again. Steam hours, last played and (if they followed the old account) sale alerts follow it. *Sign in with another account* opens Steam's sign-in. Hub never sees, types or stores a password, and won't switch while a game is running.
- **Keep the family running after updates (2.19):** Hub remembers which Hallow apps are running. When one goes away and its installed exe changes within a few minutes (it was updated), Hub waits until the new exe has stayed the same for 5 seconds and starts it again in the tray (`--tray`), once more if it exits straight away, then says so once - *Updated and restarted: Hallow Gear 1.3.1* - held while you play. An app you closed yourself (no new exe) stays closed, apps that weren't running are never started, and Hallow Browser is never reopened (just *Hallow Browser was updated - open it when you like*). Settings > **Restart family apps after updates** (on) with a chip per app to leave one out; the Family page has **Start the apps I usually run** (the ones running when Hub last stopped). Percentages are written without a space everywhere Hub shows them (45%).
- **The newer apps' newer data (2.20):** the Family page reads what the newer apps now say about themselves. **Hallow VPN 1.2.6+**: Connect / Disconnect only when Windows won't ask (its own `needsUac`), the reason in the tooltip otherwise (NordLynx, or no saved Nord login - "Windows login saved / needed" on the card), and Connect fastest is one-off (`--keep-target`): your own server stays picked in Hallow VPN. **Hallow Tasks**: live numbers from its fast `quick` answer (asked in the background, never on the window's thread), busy apps, and "2 not responding" with a button to its Processes. **Hallow Email 1.1**: why an account needs attention ("Work stuff: Sign-in failed" - your own label only when it isn't an email address, otherwise "Account 2") and unread per account in the tooltip. **Hallow Home**: Demo mode shows as *Demo*. **Hallow Gear** gets a card: the lowest batteries, "last known · 12 min ago", "waiting for its battery report (game running)" and **Refresh** (never during a game; Gear allows one every 30 s and Hub says when to try again). **Hallow Mixer 3.27**: "Spotify ad muted" and "3 ads muted today". As always only counts and states pass Hub's privacy filter, and percentages read 45%.
- **Family checkup (2.21):** Family page > **Run checkup** looks at the whole family and marks each line OK, *look at this* or a *problem*, with a one-click fix where it's safe or the exact steps: **updates** (Hallow Setup 1.18's `--list --check` against the latest GitHub releases; **Update** hands the app to Setup), the **apps you usually run** that aren't running (**Start**, in the tray), **settings stuck in Claude's sandbox** (Hallow data under `%LOCALAPPDATA%\Packages\Claude_*\LocalCache` that's newer than yours or missing from it - **Bring settings back** quits those apps through their own Quit, backs up your folders to `%USERPROFILE%\Hallow data backup\<date>` (not Documents - Ransomware protection blocks that), copies the newer files only as they are, and starts the apps again; Hub's own settings follow at its next start), **settings that must be there** (Hallow VPN's Nord service credentials - the file is only checked to exist, never read; your Hallow Keys vault; Hallow Gear running for battery alerts), **notifications** Windows has switched off for a Hallow app (read only, a link to Settings > System > Notifications), **backups** (Vault's Hallow family backup has a destination and ran recently - Back up now; Keys' safety checklist; the Authenticator's last backup on this PC), **Ransomware protection blocks** (Hallow Guard 1.10's count, and Vault's blocked destination - Open Guard's Allow helper) and **Start with Windows** for the apps you run every day (Hub's own switch here, Open its settings for the others). A quiet **weekly checkup** (Settings, on) never runs during a game and leaves one note only when something needs a look. `status.json` gets `checkup` (last run, problems, warnings) and the pipe answers `checkup` (the last result: ids, levels, plain titles - no paths or file contents) and `checkup run`.
- **Real-world checks (2.22):** Family page > **Real-world checks** lists what only your real PC, games and phone can prove: NordLynx connects and no leaks (Hallow VPN), the leak drill and VPN on demand (Hallow Torrents), the Authenticator on your phone, NordPass from the Chrome Web Store (Hallow Browser), Spotify ads muted (Hallow Mixer), a kill sound saving a clip (Hallow Clips) and the 1% low line (Hallow Overlay). Each turns green **by itself** when the app's own status shows it worked (Hub reads the status files every 2 minutes, every 10 seconds while the list is open), or mark it with **Worked** / **Didn't work**; **Try it** opens the right app on the right page. A pass is kept; a failure the app reports later turns it red. Saved in `%APPDATA%\HallowHub\real-checks.json` (ids, states, times); the pipe answers `realchecks`.
- **What's new in 2.23 - Hallow Capture and Hallow Display:** both join the Family page's *Everyday* group and the Hallow icon (a fixed place among the newer apps; *Start a Hallow app* starts them with `--tray`). **Hallow Capture** (camera icon): *3 captures today*, *Clipboard history: 120 items* or *Clipboard history paused*, with **Capture a region** (`capture region`), **Clipboard history** (`open history`) and **Pause / Resume history** (`pause on|off`). **Hallow Display** (display icon): *Game profile: ELDEN RING*, *Playing X - no profile* or how many profiles it has, and whether these monitors have a saved window layout, with **Put windows back** (`layout restore`, greyed until a layout is saved), **Night mode** (`night`, says on / off), **Stop game profile** (`profile restore`, while a profile or a test runs) and Settings. The privacy filter reads only Capture's `running`, `capturesToday`, `historyCount`, `paused` and Display's `running`, `profileActive`, `game` (a short name only - no path or address), `profileCount`, `layoutKnown`, `testRunning` - never clipboard content, file names or window titles. Launch checklists never close either app (Display must be asked to `quit` so it puts display changes back - Bring settings back does that), and the checkup's sandbox check covers `HallowCapture` / `HallowDisplay` like every `Hallow*` folder.
- **What's new in 2.24 - Hallow Find:** the family's instant search joins the Family page's *Everyday* group and the Hallow icon (a fixed place among the newer apps; *Start a Hallow app* starts it with `--tray`, and Hub starts it again with `--tray` after an update like the others). **Hallow Find** (magnifying-glass icon): *1,593,386 files and folders indexed* with the shortcut that opens it and when it last rebuilt, *Indexing your drives - 45%* and how many it has found so far, *Catching up with changes* or *Indexing paused for a game*, with **Search** (`open` - its search bar on this PC), **Rebuild index** (`rebuild`, greyed while it's indexing) and Open (its settings). The privacy filter reads only `running`, `indexState`, `entries`, `files`, `folders`, `progress`, `scanned`, `pausedForGame`, `lastRebuild`, `hotkey` (a short key name) and `hotkeyFallback` - never a file name, folder, path or search, and Find's pipe has no command that would return one. Launch checklists leave it alone as they always could (nothing to lose: its index is a cache saved every 10 minutes and on quit, and its walk already pauses while a game runs). The checkup points its Start with Windows at Hallow Setup, and the sandbox check skips `Local\HallowFind` (the rebuildable index - every file name the sandboxed copy saw) while still checking its settings in `Roaming\HallowFind`.
- **Game details:** description, genres, features, developer, release date and screenshots for Steam games (Steam's public store data, cached a month), and filters by genre and feature.
- **Play status and ratings:** Playing, Beaten, Completed, On hold, Abandoned, Plan to play and your own stars, as filters and sorts; a search that also finds genres, developers, notes and collections (genre: dev: status: col: note: store:).
- **Emulators and ROMs:** your own emulator profiles and ROM folders - every ROM becomes a game with playtime, collections and Big Picture.
- **News and charts:** patch notes and news on each Steam game's page (Steam's public news, plain text, Read more in your browser), and hours per week and per month in Stats.
- **Library backup:** collections, notes, pins, hidden games, your names and pictures, settings and playtime history in one zip - import it on another PC (games matched by store and name). No passwords or keys in it.
- **Sale alerts** (opt-in): Hub checks your public Steam wishlist once a day and tells you when something is on sale or below a price you set.
- **Hallow accent:** uses the colour you pick in Hallow Toolkit (game glows keep their own). **Crash reports** stay on this PC - after a crash Hub tells you once and can show the details.
- **What should I play, your way (2.12):** right-click Surprise me for From my backlog (Plan to play, and installed games you've never started - Ctrl+Shift+R), one of your favorites, or one you haven't played in a month. Stats gets a **Your library** section: play status split, backlog, finished games, your ratings.
- **Links on every game (2.12):** Steam store page, community hub and guides, PCGamingWiki and HowLongToBeat (both open the site in your browser - Hub fetches nothing from them), plus links of your own. Also on the right-click menu.
- **Close apps when a game starts (2.12):** pick apps (a browser, a sync app...) to close like clicking X when the game starts, opened again when it closes. Windows, game launchers and the Hallow apps are never closed. The When this game starts card lists everything that happens.
- **Filters that combine** (store, size, last played, playtime) with the chips, search and sort; **hide** tools and test servers (the Hidden filter brings them back). Favorites, search, sort by recent / most played / A to Z / size / store. Lives in the tray so playtime keeps counting.

Built with the C# compiler that ships with Windows (.NET Framework 4.8): run `build.ps1`. No admin needed to install or run.
