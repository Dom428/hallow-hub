HALLOW HUB - all your games in one place

HOW TO INSTALL
1. Right-click the zip > Properties > tick "Unblock" > OK
2. Right-click the zip > Extract All
3. Double-click INSTALL.bat (no admin needed - it installs to your user folder)
4. Hallow Hub opens. It's in your Start menu and on your Desktop.

WHAT IT DOES
- Finds your Steam, Battle.net and Epic Games games by itself, with their real artwork
  (from Steam's own cache - nothing is downloaded). Add anything else with "Add game".
- Play from one place. Double-click a cover, or select it and press Play.
- Counts your playtime - for any game running from its folder, however you start it.
  Today / this week / total, and "last played".
- When a game starts, it can:
    * switch Hallow Mixer to a preset you pick for that game
    * turn on a Hallow Toolkit game session (closes your Boost apps, High performance power)
  and put everything back when the game closes.
- Favorites, hide games you never play, sort by recent / most played / A to Z, search.
- Lives in the tray so playtime keeps counting. Settings > Start with Windows if you like.

UNINSTALL
Windows Settings > Apps > Hallow Hub > Uninstall. Your games are not touched.
