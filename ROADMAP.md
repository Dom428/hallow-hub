# Hallow Hub roadmap

| Version | What |
|---|---|
| **1.0** | Library (Steam, Battle.net, Epic, added games), playtime, Mixer preset and Toolkit game session per game, tray |
| **1.1** | Merged duplicates (Play on), Steam hours, update and size badges, Continue playing, colour glow, Stats |
| **1.2** | Game settings (launch options, run as admin), collections, Surprise me, keyboard, Xbox controller |
| **1.3** | Updates from GitHub and What's new, notices installs and updates by itself, Steam download progress, --play and desktop shortcuts |
| **1.4** | Storage page with drive bars, clean-up suggestions, uninstall through the launcher, Biggest first, Needs update / Not played lately filters |
| **1.5** | EA app, Ubisoft Connect, GOG, Riot and Xbox games; your own name, cover and banner per game |

## Next

### 1.6 - Session helpers
- Open apps with a game (Discord, OBS, Medal) and close them after
- Break reminder after a long session, and an optional daily limit per game
- Session history: every session with its date and length

### 1.7 - Look and feel
- Cover size slider and a compact list view
- Slow-moving banner art
- Notes per game (keybinds, loadouts, codes)
- Pin games to the top

### 1.8 - Share
- Discord post when you start a game (opt-in, uses Hallow Toolkit's webhook)
- Weekly recap ("12h this week, mostly Delta Force"), play streaks
- Export your playtime to a spreadsheet (CSV)

### 1.9 - Phone and PC health
- Start a game from your phone (Hallow Toolkit's dashboard)
- PC check before you play: free RAM, CPU and GPU temperature, disk space

### 2.0 - Big Picture
- Full-screen mode for the couch, made for a controller
- Quick launcher pop-up from the tray icon
